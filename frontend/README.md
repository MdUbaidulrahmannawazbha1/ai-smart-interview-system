# AI Smart Interview System - Frontend

React-based frontend for the AI-Powered Smart Interview System.

## Features

- Generate interview questions based on job role and difficulty
- Evaluate candidate answers using AI
- Display real-time evaluation results with scores and feedback
- Interactive and user-friendly interface

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## API Integration

The frontend connects to the backend API at `http://localhost:8000/api/v1` by default.

## Technologies

- React 18
- Vite
- Axios for API calls
